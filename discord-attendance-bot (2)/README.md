# نظام إدارة وحضور بوت الديسكورد وسيرفر فايف ام برافا (Brava FiveM & Discord Attendance System)

نظام متكامل واحترافي يربط بين سيرفر الديسكورد وخادم فايف إم (FiveM Brava) لمتابعة وتسجيل حضور وانصراف الإداريين والأعضاء في رومات الفويس المحددة تلقائياً، مع لوحة تحكم تفاعلية وإشعارات ذكية وسجلات شفتات دقيقة.

---

## 🌟 الميزات الرئيسية

1. **تسجيل الحضور الصوتي الذكي**:
   - رصد أوامر تسجيل الدخول (`د`) والخروج (`خ`).
   - التحقق من انضمام العضو إلى روم الفويس المخصص للفريق خلال مهلة محددة (افتراضياً 5 دقائق).
   - إرسال إنذارات تلقائية في حال عدم الدخول لروم الفويس، وبلاغات لشات الإدارة.

2. **نظام الفرق والأقسام (Teams)**:
   - إدارة كاملة للفرق (فريق السيناريو، فريق الباند والرقابة، فريق الدعم الفني، فريق الإدارة، وغيرها).
   - تخصيص رومات الفويس وشاتات الحضور لكل فريق على حدة.
   - إمكانية إضافة وحذف الفرق حصراً من صفحة الإعدادات بصلاحيات مخصصة.

3. **حسابات ولوحة تحكم بصلاحيات دقيقة (RBAC)**:
   - حساب القائد (Owner): صلاحيات كاملة لإدارة الفرق، البوت، المستخدمين والسجلات.
   - حسابات المشرفين والأعضاء برتب مخصصة.
   - تسجيل دخول سريع بواسطة اسم لاعب فايف إم (FiveM In-Game Username) بعد إنشاء الحساب.

4. **سجل الشفتات والتقارير**:
   - متابعة مدة الشفتات بدقة بالدقائق والساعات.
   - تصدير تقارير الحضور والشفتات بصيغة CSV.

## 🚀 طريقة التثبيت والتشغيل

### 1. المتطلبات الأساسية
- تثبيت **Node.js** (الإصدار 18 أو أحدث)
- تثبيت **npm** أو **bun** أو **yarn**

### 2. تثبيت الحزم والمكتبات
افتح موجه الأوامر (Terminal / CMD) في مجلد المشروع ونفّذ:
```bash
npm install
```

### 3. إعداد متغيرات البيئة (اختياري)
قم بنسخ ملف `.env.example` إلى `.env`:
```bash
cp .env.example .env
```
يمكنك وضع توكن بوت الديسكورد في ملف `.env` أو إدخاله مباشرة من صفحة الإعدادات في لوحة التحكم.

### 4. تشغيل المشروع في وضع التطوير (Development)
```bash
npm run dev
```
سيفتح المشروع على: `http://localhost:3000`

### 5. بناء وتشغيل المشروع في وضع الإنتاج (Production)
```bash
npm run build
npm start
```

├── server.ts               # سيرفر Express + منطق بوت الديسكورد وتخزين البيانات

├── package.json            # تعريف الحزم وأوامر التشغيل
